# docs/assets · 素材目录（L2）

> 3.18.0 · 2026-11-25 · 维护：Yonty Bot contributors

README 和文档用到的图片、示意图，以及能重新生成它们的源文件。

| 路径 | 放什么 |
|---|---|
| `hero/` | 主视觉和社交卡片（分享链接时显示的图） |
| `diagrams/` | 正文配图：派活流程、三层分工、验证闸门、权限边界；中英各一套，深浅色各一版，格式 SVG |
| `source/` | 源文件和生成命令，按 `hero/`、`diagrams/` 分子目录；每个成品都要能从这里重新生成 |

规则：

- 单个素材不超过 5 MB，仓库里素材合计不超过 15 MB。更大的走 Release 附件，文档里放链接。
- 配图是按真实流程重绘的，不是实拍。图注写明“示意”。
- 素材里不放真实用户名、群名、ID、服务器地址和密钥。用占位内容。
- 新增或改名素材后，更新本页。
