规则：

- 单个素材不超过 5 MB，素材合计不超过 15 MB。更大的走 Release 附件，文档里放链接。
- 主视觉和示意图是生成的插画，图上的字按代码写，逐字核对过。换图要同时更新 `source/generated/` 里的记录，否则 CI 不过。
- 截图是实拍，图注写明是节选、哪些地方换过。
- 素材里不放真实用户名、群名、ID、服务器地址和密钥。截图里的人名、头像换成占位，水印去掉。
- 新增或改名素材后，更新本页。

## 截图

`feishu-task.png` 是 2026-11-26 截的，来源是作者实例里 yonty-bot 3.18.0 那次的私聊和飞书任务。重截照下面做：

1. 在浏览器里打开飞书网页版和机器人的私聊。点会话右上角的任务按钮，打开要截的任务，切到“任务执行”。
2. 在开发者工具里跑脚本。消息列表是虚拟滚动，直接隐藏消息会错位，所以把要截的几条消息复制到一层静态列表里，盖在原列表上。
3. 人名、机器人名换成占位：机器人“小助理”，主人“周宇”，机器人的描述换成“Yonty Bot”。头像换成代码画的字母图：机器人是深色底上的“Y”，主人是蓝底白字“周宇”。没有用生成的图片。
4. 水印层用样式表隐藏。直接改水印元素，飞书会马上补回。
5. 截之前核对：截取范围里看得见的文字没有真实人名、公司名和别的项目名，原头像一个不剩，水印层不显示。
6. 用开发者工具协议按 2 倍像素截取聊天栏和任务栏（`Page.captureScreenshot` 加 `clip`），不截左边的会话列表。
7. 截完按原尺寸逐块看一遍，再把亮度拉开，看有没有残留的水印。
8. 在本机剪图：合进主干那条回复只留第一段，剪掉后两段当时的待办（升级提示、分支保护）。右边任务列表剪掉同样高度的开头两条，两栏才一样高。剪口选在整行空白处，剪之前核对剪口两边的行逐像素相同。

第 2 到 4 步的改动只在本机网页里，关掉标签页就没了，不改飞书里的数据。
