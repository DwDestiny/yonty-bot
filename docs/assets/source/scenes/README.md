# 群聊场景图的记录

> 3.19.10 · 2026-11-26 · 维护：Yonty Bot contributors

`docs/assets/scenes/` 里的两张图是摆拍。人名、群名、台词都是编的，界面是飞书网页版，消息样式照飞书原样。这里记下台词、机器人的哪些话是服务的固定格式，以及怎么重拍。

| 文件 | 放什么 |
|---|---|
| `scenes.json` | 两段对话：谁说的、几点、引用哪条消息、正文 |
| `compose.js` | 拼图脚本：在飞书网页版里把一段对话拼成静态的消息列表，再核对截取范围里的字和图 |

## 两段对话

- `group-banter.png`（斗嘴）：登录超时，老陈和小林互相甩锅。老陈 @ 机器人问是谁改的，机器人查了提交记录，指出是小林那次“改按钮颜色”的提交把超时从 30 秒改成了 3 秒。这个群开了旁听，老陈说“我那是信任你”时，没人 @ 机器人，它也接了一句梗。小林让机器人改回去，机器人写好任务书，在群里 @ 主人周宇。周宇批了，任务排上。

## 机器人的话哪些照代码

机器人的话分两种。服务拼出来的固定格式，图里照代码原样写。模型自己写的回复，图里是编的例子，真用时每次措辞不同。

| 图 | 机器人的消息 | 哪种 | 出处 |
|---|---|---|---|
| 斗嘴 | 查了提交记录：…… | 模型回复 | 守则让它查代码和提交记录来回答同事（`app/rules/persona-work.md`） |
| 斗嘴 | 这份信任，3 秒就超时了。 | 模型回复，旁听时插话 | `app/rules/base.md` 的“群聊旁听” |
| 斗嘴 | 好，改回 30 秒……（等你批的那条） | 第一句是模型回复，从“归到”起是固定格式 | `app/bridge.py` 的 `dispatch_one`、`thing_line` |
| 斗嘴 | 批了，shop#31 排上了。 | 固定格式 | `app/bridge.py` 的 `task_approve` |
| 干活 | 好，转给 shop 的项目经理排进这一版。 | 模型回复 | `app/rules/base.md`：主人的活写 `[转交]`，交给项目经理 |
| 干活 | 【shop】……派了 shop#32 …… | “【shop】”和“派了……”一句是固定格式，中间是项目经理的模型回复 | `app/bridge.py`：群里项目经理的话前面加“【项目名】”直接发出；“派了……”来自 `dispatch_one` |
| 干活 | 返回 409…… | 模型回复 | 无 |
| 干活 | 下单页的“仅剩 N 件”做好了…… | 模型回复，服务把它引用派活的那条消息发出 | `app/bridge.py` 的 `task_say` |

等你批的那条里的几个值：

- 仓库：写仓库的绝对路径，也就是 `tasks.check_repo` 返回的路径。图里用占位路径 `/home/dev/work/shop`。
- 模型“sonnet · 思考 medium”：有验证命令、在本机跑的开发活，服务先用这一档（`tasks.pick_model`）。
- 检查点：同类任务最近 10 个的花费中位数乘 1.5（`tasks.budget_basis`）。同类记录不到 2 个时，用默认值 20。
- 24 小时：`approval_hours` 的默认值（`app/config.example.json`）。

干活这段没有“开工”消息，因为项目经理按方案派的任务，开工和进展记在看板上，不在群里逐条发（`app/bridge.py`）。

改了上面这些固定格式，要重拍这两张图。

## 怎么拍

1. 在 Chrome 里打开飞书网页版和机器人的私聊。私聊里要有机器人带引用的富文本回复，也要有自己发的消息，脚本拿它们当消息样式。
2. 用开发者工具协议把页面设成宽 1136、高 2600、2 倍像素（`Emulation.setDeviceMetricsOverride`）。这时聊天栏宽 520。
3. 在页面里运行 `compose.js`，再运行 `await ybCompose(scene)`。`scene` 是 `scenes.json` 里 `scenes` 下的一段。它返回截取范围 `clip`。
4. 运行 `ybCheck(scene, clip)`。返回的三个列表都要是空的：截取范围里看得见的字都在这段台词里，或者是飞书界面上的“消息”和“+”；看得见的图片都是脚本画的头像。
5. 用 `Page.captureScreenshot` 加上 `clip` 截图。
6. 把顶栏左上角、右上角露出来的深色圆角填成顶栏的底色 `#FBFBFC`。
7. 按原尺寸看一遍，再看右边空白处的颜色是不是都一样，确认没有残留的水印。

第 2 到 4 步的改动只在本机网页里，关掉标签页就没了。这个过程不发消息，也不改飞书里的数据。
