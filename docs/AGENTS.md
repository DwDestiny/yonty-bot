# docs/ · 目录说明（L2）

> 3.18.0 · 2026-11-25 · 维护：Yonty Bot contributors

`docs/` 放给人和智能体读的说明：上手、场景、原理、参考、排障，以及方案和素材。入口是 [README.md](README.md)，按这五类列全部文档。现行文档写的是当前版本的事实；方案文档写下一版要做什么，实现后把结论并进现行文档，再移到 `archive/`。现行文档的路径不动（测试和外链指着它们）。

| 文件 | 放什么 | 类别 |
|---|---|---|
| `README.md` | 文档索引：五类分类，每篇一句话 | 入口 |
| `quickstart.md` | 手动安装、上手 | 现行 |
| `usage.md` | 日常使用和场景 | 现行 |
| `troubleshooting.md` | 按现象排障 | 现行 |
| `releasing.md` | 发版流程和发布说明写法 | 现行 |
| `ci.md` | CI：两台机器分着跑全量测试、页面检查、外部合并请求怎么验 | 现行 |
| `architecture.md` | 分层、团队（一件事一个负责人）、智能体之间的消息、路由、决策点、路线 | 现行 |
| `tasks.md` | 长任务：流程、命令、编号、权限、存储、额度、团队与资源 | 现行 |
| `schedules.md` | 定时任务：怎么建、时间表、`[下次]`、探针、权限范围、怎么看和停 | 现行 |
| `config.md` | `config.json` 的全部字段 | 现行 |
| `boundary.md` | 人设、身份、私密资料、钩子的三层防线 | 现行 |
| `cache.md` | 缓存的原理、验证、排查和花费预期 | 现行 |
| `guide.md` | 搭建指南，给帮用户安装的智能体看 | 现行 |
| `setup.md` | 安装：运行位置、飞书应用、后台配置 | 现行 |
| `wecom.md` | 企业微信渠道 | 现行 |
| `plan-2.0.md` | 跳转页，指向 `archive/plan-2.0.md`，保住旧链接 | 跳转 |
| `archive/` | 已实现的方案，只读归档。现有：`plan-2.0.md`（2.0 方案：三层智能体、投递、资源放行、定时任务和权限范围；对话原文和真实场景已改成转述） | 归档 |
| `assets/` | 图片、示意图和源文件，成员见 [assets/README.md](assets/README.md) | 素材 |

规则：

- 新增、改名、删除文件后更新本表，再更新根目录 `AGENTS.md` 的 `docs/` 一行。
- 方案文档实现后，把结论并进现行文档，方案文档标“已实现”或删掉，一个事实只留一份。
- 归档文档里不放对话原文、真实场景和真实人名、项目名；写设计和结论。
- 仓库根目录的 `CHANGELOG.md`、`CONTRIBUTING.md`、`SECURITY.md`、`CODE_OF_CONDUCT.md` 不在本目录，在 `README.md` 的“参考”里列出。
