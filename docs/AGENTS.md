# docs/ · 目录说明（L2）

> 3.2.0 · 2026-11-23 · 维护：Yonty Bot contributors

`docs/` 放给人和智能体读的说明：现行设计、搭建、配置、排查，以及方案。现行文档写的是当前版本的事实；方案文档写下一版要做什么，实现后把结论并进现行文档。

| 文件 | 放什么 | 类别 |
|---|---|---|
| `architecture.md` | 分层、团队（一件事一个负责人）、智能体之间的消息、路由、决策点、路线 | 现行 |
| `tasks.md` | 长任务：流程、命令、编号、权限、存储、额度、团队与资源 | 现行 |
| `schedules.md` | 定时任务：怎么建、时间表、`[下次]`、探针、权限范围、怎么看和停 | 现行 |
| `config.md` | `config.json` 的全部字段 | 现行 |
| `boundary.md` | 人设、身份、私密资料、钩子的三层防线 | 现行 |
| `cache.md` | 缓存的原理、验证、排查和花费预期 | 现行 |
| `guide.md` | 搭建指南，给帮用户安装的智能体看 | 现行 |
| `setup.md` | 安装：运行位置、飞书应用、后台配置 | 现行 |
| `wecom.md` | 企业微信渠道 | 现行 |
| `plan-2.0.md` | 2.0 方案：三层智能体（主控、项目经理、执行层）、投递、资源放行、定时任务和权限范围、各层边界、令牌成本 | 方案，已实现（2.0.0） |

规则：

- 新增、改名、删除文件后更新本表，再更新根目录 `AGENTS.md` 的 `docs/` 一行。
- 方案文档实现后，把结论并进现行文档，方案文档标“已实现”或删掉，一个事实只留一份。
